# Changelog

## 1.0.0 — 2026-08-10

### Added
- Initial release
- `ContactModel` — customer contact with segment type, lead score
- `InteractionModel` — call/email/meeting history tracking
- `CustomerSegment` — Individual vs Business classification
- `InteractionType` — Call/Email/Meeting/WhatsApp types
- `CrmRepository` — CRUD contacts, track interactions
- `ContactsNotifier` — list/create/update contacts, search/filter
- `MoeCrmConfig` — configurable API URL + lead scoring support

### Features
- Lead scoring system
- Contact segmentation (individual/business)
- Interaction history logging
- Full name generation
- Search & filter by segment/date
